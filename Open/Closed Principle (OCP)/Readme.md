Single Responsibility Principle (SRP)

Definition:

A class, function, or module should have only one reason to change.

In simple words:

One thing = One responsibility.
How to Identify an SRP Violation


WHEN USE : 
Does this class have more than one job?
Would different teams change this class for different reasons?
Does it mix unrelated business logic?
If the answer is yes, consider splitting it into multiple classes or modules.
